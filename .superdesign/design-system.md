# Lenterne dual-storefront design system

## Product architecture
Two coordinated storefronts — Brindes and Ferragens — with identical visual language and separate catalog content. Shared commerce API, cart, quote flow, header and footer.

## Visual system
- Black and near-black surfaces with off-white text.
- Lenterne red is the sole action accent.
- Continuous liquid-red MP4 for feature backgrounds; subtle red neural noise elsewhere.
- Large geometric display typography, neutral body typography and monospace uppercase eyebrows.
- Editorial, cardless grids; product photography carries hierarchy.
- Thin rules, disciplined spacing, small-radius action buttons.

## Structure
Home: full-bleed photographic hero → centered use-case statement → editorial product grid → animated process section.
About: animated editorial hero → manufacturing narrative → four-item capability rail → contact CTA.
Manager: restrained operational workspace with authentication, product list and focused editor; no marketing hero or decorative cards.

## Motion
Background MP4 never exposes controls and loops continuously. Product images use restrained hover scale. Buttons use a two-pixel lift.

## Responsive
Desktop uses asymmetrical photography; mobile stacks media before copy. No horizontal overflow. Both storefronts use the same breakpoints and component geometry.
