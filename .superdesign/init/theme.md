# Theme source of truth

The complete theme is implemented in:

- `packages/ui/src/tokens.css` — semantic colors, typography, spacing, radii and motion tokens.
- `packages/ui/src/base.css` — reset, shell, buttons, status and accessibility behavior.
- `packages/storefront/src/styles.css` — complete storefront composition and responsive rules.

System: black surfaces, off-white type, Lenterne red accent, geometric display typography, monospace eyebrows, thin dividers, restrained radii, continuous red liquid MP4 backgrounds and subtle red WebGL neural noise. Both channels must use the same visual system.
