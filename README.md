# Lenterne V3

Terceira proposta visual da plataforma Lenterne, completamente separada das versões V1 e V2.

## Direção

Catálogo industrial contemporâneo com composição de revista, navegação técnica, vitrines assimétricas, live wallpaper MP4 e Neural Noise vermelho. Reutiliza apenas dados, assets e regras operacionais das versões anteriores.

## Aplicações locais

- Brindes: http://localhost:3300
- Ferragens: http://localhost:3301
- Administração: http://localhost:3302
- API: http://localhost:4300

## Comandos

- `npm install`
- `npm run dev:brindes`
- `npm run dev:ferragens`
- `npm run dev:admin`
- `npm run dev:api`
- `npm run typecheck`
- `npm test`
- `npm run build`

Copie `.env.example` para `.env` e substitua todas as credenciais antes da homologação externa.
